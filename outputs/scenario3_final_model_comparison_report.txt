Scenario 3 Model Evaluation and Comparison
=========================================

Overview
--------
Source file: outputs/scenario3_validation_input.parquet
Split file: outputs/scenario3_split_assignments.parquet
Base shape: (1050000, 31)
Labelled rows: 985,876

Data splits:
- Train: 591,525 rows, 132,115 positive (22.33%)
- Validation: 197,175 rows, 44,038 positive (22.33%)
- Test: 197,176 rows, 44,039 positive (22.33%)

Models
------
This comparison evaluates five pre-trained models without retraining or retuning:

1. Decision Tree: Fitted sklearn Decision Tree pipeline
   - File: models/scenario3_decision_tree_pipeline.joblib
   - Parameters: max_depth=8, min_samples_split=20, min_samples_leaf=10

2. Random Forest: Fitted sklearn Random Forest pipeline
   - File: models/scenario3_random_forest_pipeline.joblib
   - Parameters: n_estimators=200, max_depth=12, min_samples_split=15

3. XGBoost: Fitted XGBoost pipeline
   - File: models/scenario3_xgboost_pipeline.joblib
   - Parameters: n_estimators=200, max_depth=6, learning_rate=0.1

4. Neural Network: Keras Dense model reusing Decision Tree's fitted preprocessor
   - File: models/scenario3_neural_network.keras
   - Architecture: Dense(128)→BN→Dense(64)→BN→Dense(32)→Dense(1)
   - Trained with EarlyStopping on validation ROC-AUC

5. LSTM Demo: Keras LSTM model for educational purposes
   - File: models/scenario3_lstm_demo.keras
   - DISCLAIMER: This model uses exactly ONE timestep per patient.
     It is an educational sequence wrapper only and does not learn
     temporal changes over time. Each patient contributes one observation.
   - Architecture: LSTM(64)→LSTM(32)→Dense(16)→Dense(1)

Model Selection Criterion
------------------------
Among Decision Tree, Random Forest, XGBoost, and Neural Network,
the model with the highest validation ROC-AUC was selected.
In case of ties, F1 was used as tiebreaker.
LSTM is included as an educational comparison with the caveat above.
